# 군체 형상 생성

## 개요

군체 보스는 정해진 수의 구체를 머리, 몸통, 팔다리에 나눠 거인 형상을 만듭니다. 부위마다 배정된 구체 수에 맞춰 도형 크기를 정하고, 도형 안에 구체가 들어갈 자리를 만든 뒤 연결점에 맞춰 부위를 조립합니다.

## 기본 도형으로 부위 정의하기

`USwarmFormDefinition`은 거인을 구성할 부위의 설정을 담는 데이터 에셋입니다. 예를 들어 몸통을 넓은 박스, 팔을 세로로 긴 박스로 정의하고, 팔의 부모를 몸통으로 지정할 수 있습니다. 두 박스는 구체의 중심이 들어갈 영역입니다. 실제 화면에서는 각 영역 안에 배치한 구체들이 모여 부위의 모양을 이룹니다. [`USwarmFormDefinition`](../Source/SwarmBoss/Boss/SwarmFormDefinition.h)

| 부위 설정 | 정하는 것 |
| --- | --- |
| `Shape`, `BoxHalfExtentsRatio` | 구체 중심을 배치할 영역이 구형인지 박스형인지 정합니다. 박스의 경우 가로·세로·높이의 비율도 정합니다. |
| `AllocationWeight` | 전체 구체 중 이 부위에 배정할 비중을 정합니다. |
| `ParentPartId` | 이 부위가 어느 부위에 붙는지 정합니다. 몸통은 최상위 부위이고, 팔은 몸통에 붙습니다. |
| `ParentAnchor`, `ChildAnchor` | 부모와 자식에서 서로 맞출 위치를 정합니다. 팔이라면 몸통의 옆면과 팔의 위쪽에서 각각 연결점을 잡습니다. |

## 부위별 구체 수와 크기 정하기

플레이가 시작되면 `ASwarmBossManager::GenerateInitialParts()`가 전체 구체 수인 `InitialParticleCount`를 부위별 가중치에 따라 나눕니다. 각 부위의 몫은 `전체 개수 × 부위 가중치 / 전체 가중치 합`을 정수로 버린 값입니다. 예를 들어 몸통과 팔만 있고 가중치가 2:1이라면, 구체 10개를 먼저 몸통 6개와 팔 3개로 나눕니다. 남은 1개는 `RemainderPartId`로 지정한 부위에 더합니다. 몸통이 그 부위라면 최종 배분은 7개와 3개입니다. [`GenerateInitialParts()`](../Source/SwarmBoss/Boss/SwarmBossManager.cpp#L440)

부위에 몇 개를 넣을지 정하면, 샘플러는 그만큼의 구체를 배치할 공간을 계산합니다. 구체 하나의 반지름은 고정합니다. 두 구체의 중심이 구체 하나의 지름만큼 떨어져 있으면 표면이 맞닿습니다. 여기에 표면 사이에 남겨 둘 여유 거리(`SpacingMargin`)를 더해, 두 중심이 최소한 얼마나 떨어져 있어야 하는지 정합니다. 이 거리를 `d`라고 합니다. 초기 부피는 `구체 수 × d³ / PackingCoefficient`입니다. 같은 간격과 배치 계수에서 초기 부피는 구체 수에 비례하므로, 단위 부피당 목표 구체 수가 일정합니다. 박스는 축마다 같은 배율을 적용해 원래의 가로·세로·높이 비율을 유지합니다. `PackingCoefficient`가 클수록 같은 개수를 더 작은 초기 부피에 배치하도록 시도합니다. [`FSwarmShapeSampler::GenerateTargets()`](../Source/SwarmBoss/Swarm/SwarmShapeSampler.cpp#L188)

피격 후에도 같은 가중치 규칙으로 살아남은 구체를 나누고, 개수가 달라진 부위의 크기와 목표 좌표를 다시 계산합니다. 구체 하나의 크기는 그대로 유지하면서 거인 전체를 남은 수에 맞춰 조정할 수 있습니다. [피격과 재구성](HitAndReconstruction.md)

## 도형 안에서 구체가 들어갈 자리 찾기

각 부위 안을 구체로 불규칙하게 채우면서도, 두 구체의 중심 사이에는 일정 거리 이상을 확보하고 싶었습니다. 이 두 조건을 만족하는 위치를 찾기 위해 3D Poisson Disk Sampling을 선택했습니다.

1. 도형 안에 첫 점을 무작위로 놓습니다. 이미 배치한 점 하나를 골라, 그 점에서 `d` 이상 `2d` 이하 떨어진 곳에 무작위 후보를 만듭니다.
2. 후보가 도형 밖에 있으면 버립니다. 도형 안에 있으면, 후보가 속한 격자 칸과 그 주변 칸의 점만 확인합니다. 이미 배치한 점 중 하나라도 `d`보다 가까우면 후보를 버립니다.
3. 두 조건을 통과한 후보는 새 점으로 채택하고, 그 주변에서도 다음 점을 찾습니다. 한 점 주변에서 정해진 횟수만큼 시도해도 새 점을 찾지 못하면 그 점을 후보 생성 목록에서 뺍니다.

목표 개수에 도달하자마자 멈추면 구체가 시작점 주변에 몰릴 수 있습니다. 그래서 더 시도할 점이 없어질 때까지 탐색한 뒤, 채택된 점 중 필요한 수만큼 무작위로 고릅니다. 점이 부족하면 최소 간격을 유지하면서 도형을 넓혀 다시 시도합니다. 허용된 확장 범위에서 목표 개수를 채우지 못하거나 후보 검사 횟수 한도에 걸리면 샘플링은 실패합니다. 초기 생성에서는 모든 부위의 샘플링이 성공한 뒤 구체를 만듭니다.

최소 간격을 검사하는 범위는 **한 부위 안의 목표 좌표 사이**입니다. 부위마다 별도의 격자를 만들어 검사하므로, 서로 다른 부위의 구체 사이 거리나 재구성 도중의 이동은 이 검사의 범위 밖입니다. 기존 `SamplingInvariants` 자동 테스트에서는 구형·박스형 도형을 여러 개수와 난수 시드로 생성해, 성공한 결과가 요청한 개수와 도형 경계 및 최소 간격을 만족하는 것을 확인했습니다. [샘플링 자동 테스트](../Source/SwarmBoss/Swarm/SwarmShapeSamplerTests.cpp#L108)

## 연결점에 맞춰 거인 조립하기

샘플러가 반환한 좌표는 도형 중심을 원점으로 하는 로컬 좌표입니다. 관리자는 이 좌표를 그대로 해당 부위의 `Instanced Static Mesh`(ISM) 컴포넌트에 넘깁니다. 좌표 하나마다 구체 메시 인스턴스 하나를 만들고, 중앙 저장소에 구체의 ID와 해당 인스턴스 번호를 기록합니다. 몸통의 ISM에는 몸통 구체를, 팔의 ISM에는 팔 구체를 배치합니다. [`AddPartParticles()`](../Source/SwarmBoss/Boss/SwarmBossManager.cpp#L814)

팔의 ISM은 몸통의 ISM에 붙습니다. `ApplyPartPlacement()`는 두 부위의 현재 크기에 맞춰 연결점의 로컬 좌표를 구하고, 몸통 쪽 연결점 바깥에 팔 쪽 연결점을 맞춥니다. 이때 바깥으로 띄우는 거리는 `Gap + 두 부위의 구체 반지름`입니다. 도형 경계는 구체 중심이 들어갈 수 있는 한계이므로, 경계에 놓인 구체의 표면은 반지름만큼 바깥에 있기 때문입니다. `Gap`은 이렇게 구체 반지름까지 고려하고 남겨 둘 여유를 정합니다. [`ApplyPartPlacement()`](../Source/SwarmBoss/Boss/SwarmBossManager.cpp#L278)

연결점은 각 축의 반길이에 대한 비율로 저장합니다. 예를 들어 박스형 몸통의 옆면을 가리키는 값은 몸통의 폭이 줄어도 새 옆면을 가리킵니다. 재구성 때 새 도형 크기로 연결점을 다시 계산하는 이유입니다. 샘플러는 초기 생성과 재구성 시점에 목표 좌표를 만들고, 이동 중에는 관리자가 매 프레임 이미 배정된 목표까지의 위치만 갱신합니다. [목표까지 이동시키기](HitAndReconstruction.md#목표까지-이동시키기)
